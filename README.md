\# Password Security Checker



A simple Python-based cybersecurity project that checks password strength and provides security recommendations.



\## Features



\- Checks password length

\- Checks uppercase letters

\- Checks lowercase letters

\- Checks numbers

\- Checks special characters

\- Detects common passwords

\- Calculates password strength percentage

\- Gives security recommendations

\- Generates a security report

\- Does not save the actual password



\## Technologies Used



\- Python

\- Regular Expressions

\- Command Prompt
